# 2. Git

Git is a distributed version control system that helps developers track changes, manage branches, and maintain a history of their work.

This section provides practical Git commands used throughout the software development lifecycle.

The guides cover local repositories, branch management, remote repositories, and recovering changes.

The examples are based on development workflows used in the ZainfoDevs Solar Site Monitoring API project.
